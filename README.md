# Tamanna Mandal — Personal Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — styling, responsive layout, selectors and hover effects
- `script.js` — mobile menu, dark mode and contact form validation

## Before publishing
1. Replace `your.email@example.com` with your real email address.
2. Replace `your-username` with your GitHub username.
3. Check that the education, skills and project descriptions are accurate.
4. You can add project demo/repository links to the project cards.

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `my-portfolio` (or another name).
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. After deployment, GitHub Pages displays your live website URL.

The contact form currently performs front-end validation only; it does not send or store messages.
